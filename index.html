Automação de Certificados de Eventos

O problema

Emitir certificados manualmente para cada participante consumia horas de trabalho repetitivo por evento.

A solução

Sistema em Python que lê planilhas Excel de participantes, gera certificados personalizados em massa e envia tudo automaticamente por e-mail (SMTP).

O resultado

Redução de horas de trabalho manual para minutos por evento — zero erro de digitação.

Pythonpandas / openpyxlSMTPExcel
Ver no GitHub
gerar_certificados.py
# Entrada → processamento → saída
participantes = ler_planilha("inscritos.xlsx")
for pessoa in participantes:
    certificado = gerar_pdf(pessoa)
    enviar_email(certificado, pessoa.email)

✓ 250 certificados enviados
✓ Tempo total: 3 min 12 s
